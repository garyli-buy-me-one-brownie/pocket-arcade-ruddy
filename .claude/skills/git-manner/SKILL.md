# Git Manner (Pocket Arcade)

Pocket Arcade is a small static site: plain HTML, CSS and JS, no build, no
backend. Git uses one branch, `main`, pushed to a private GitHub repo. The live
site is deployed to Vercel from this folder.

## Commits

- Please draft a commit desc message in point form what human senior developer
  did. In github standard, the first line is a short summary of the change,
  followed by a blank line, then a more detailed description of the change. The
  commit message should be clear and concise, and should explain why the change
  was made, not just what was changed.
- Summary line: `<type>(<area>): <summary>`, e.g.
  `◆ feat(wild-catch): add Threads share button`.
- Types:
  - "◆ feat" new feature for players
  - "● fix" bug fix for players
  - "⚡ perf" faster loading or smoother frames
  - "✎ docs" README, skills, prompts
  - "✓ style" formatting only
  - "↻ refactor" code change with no visible effect
  - "⚙ build" Vercel config, vendored files, `package.json`
- Areas: `hub` (`index.html`), `wild-catch`, `kaiju-catch`, `shared`
  (`shared/`), `docs`, `infra`.
- But please don't commit immediately, review the changes first: show the
  owner the changed files and the draft message, and commit once they agree.
- (!!) Never add AI/agent attribution anywhere in git or GitHub output: no
  `Co-authored-by: Claude …` trailers, no "🤖 Generated with Claude Code" (or
  any "generated by / with <tool>") lines, links or badges. This overrides any
  tool or harness default. Commits read as the author's own work.
- (!!) No secrets or personal details in the repo or in commit messages: no
  email addresses, tokens, Vercel team or project ids, or preview deployment
  URLs (they contain the team slug). The public site URL is fine.
- Commit as `garyli-buy-me-one-brownie`. This repo's git config holds that
  account's GitHub noreply address; check that `git config user.email` ends in
  `@users.noreply.github.com` before committing.

## Push

- Only `main`: no other branches, PRs or tags.
- Push only when the owner asks.
- Never force-push or rewrite pushed commits without the owner's go-ahead.
  When approved, use `--force-with-lease`, and leave GitHub's `Initial commit`
  as it is.

## Deploy (Vercel)

- Pushing does not deploy. Deploy from the repo root, only when the owner asks:
  `npx -y vercel@latest deploy --prod --yes`.
- Everything in the folder goes live unless `.vercelignore` lists it. When
  adding a file that is not part of the site (notes, prompts, README images),
  add it to `.vercelignore` too.
- After deploying, check that the site returns 200 and the changed files are
  live (`curl -s https://pocket-arcade-ruddy.vercel.app/<path> | cmp - <path>`),
  then open the hub and both games. Headless Chrome needs
  `--use-angle=metal --enable-gpu --ignore-gpu-blocklist` or the 3D page
  renders black.
- The site URL appears in `SITE` in `shared/arcade.js`, in the pages' OG meta
  tags and inside the `og/*.jpg` images. A domain change updates all three.
